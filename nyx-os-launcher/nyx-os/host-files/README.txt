─── Nyx OS Host Files ──────────────────────────────────────────────

Drop any .png or .jpg files in this directory, then run:

    make run

from the nyx-os/ directory. The files will be automatically
packed into disk.img and be available inside the OS.

Open the Gallery app (desktop icon) to browse and view your images.

Limitations:
  - Max 16 files
  - Max 16384 bytes per file (16 KB — bumped from 2 KB)
  - Filenames max 31 characters
  - **No spaces** in filenames (Make treats them as separators)
  - Only .png and .jpg are displayed in the Gallery
